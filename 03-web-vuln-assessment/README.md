# 웹 취약점 진단 보고서 3건

> SK쉴더스 루키즈 32기 애플리케이션 보안 · 2026.06 · 팀 5~7명 · GM Shop 진단 팀장 · GM Shop 보고서 73쪽 ([PDF 보기](gmshop-report.pdf))

<br>

## 개요

교육 과정에서 제공된 실습 쇼핑몰 세 곳을 진단하고 KISA 형식으로 보고서를 썼습니다. 진단 기준은 「주요정보통신기반시설 기술적 취약점 분석·평가 방법 상세가이드(2026)」입니다. 세 건 모두 취약점 진단과 항목별 대응방안 작성에 참여했고, GM Shop 진단에서는 팀장을 맡았습니다.

<br>

## 진단 결과 요약

| 대상 | 결과 | 주요 발견 |
| --- | --- | --- |
| JM Collection (AWS 3티어 쇼핑몰) | 20개 항목 중 16개 취약 (위험도 상 8개) | 결제 금액을 20,000원에서 10원으로 바꿔도 주문 완료 (서버 측 검증 누락), 임시 비밀번호 평문 노출, 세션 재사용, 구버전 Tomcat |
| GM Shop | 30개 항목 점검, 취약점 43건 | 백업 파일과 DB 덤프에서 관리자 계정 정보 노출, XSS로 관리자 세션 탈취 (BeEF), 파일 업로드 확장자 검증 우회, `/admin` 강제 호출 |
| Oyesmall | 11개 분야에서 취약점 확인 | Union, Blind SQL Injection으로 DB 정보 추출, 파일 업로드 검증 우회, 회원가입·게시판·관리자 페이지 XSS, 경로 조작으로 주요 파일 다운로드 |

<br>

## 진단하면서 본 공통점

세 사이트 모두 **서버가 다시 확인하지 않는다**는 문제가 반복됐습니다. 결제 금액, 파일 확장자, 관리자 페이지 접근 권한처럼 화면에서만 막고 서버에서는 검증하지 않는 부분이 가장 큰 위험이었습니다. 그래서 대응방안도 대부분 서버 측 검증을 추가하는 방향으로 썼습니다.

<br>

## 사용 도구

Burp Suite, sqlmap, Nmap, Nikto, BeEF

모든 진단은 교육 과정에서 허가된 실습 사이트를 대상으로 진행했습니다. GM Shop 보고서는 팀원 동의를 받아 공개하며, 팀원 이름과 연락처는 가렸습니다. JM Collection, Oyesmall 보고서는 요약만 정리했습니다.
